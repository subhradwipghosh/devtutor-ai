# My agent: DevTutor AI

One-liner: A conversational tutor agent that helps developers master new programming languages and frameworks with personalized learning paths, interactive quizzes, visual diagrams, and live code execution.

Tool coverage:
- Memory: Remembers student skill level (Beginner/Intermediate/Advanced), target learning goals, weak concepts, completed lessons, and quiz scores across sessions.
- Tools: Searches documentation and code examples, evaluates coding exercises, and records progress.
- Catalog/UI: A collection of learning modules, lesson cards, and interactive quiz decks rendered as rich A2UI cards.
- Image gen: Generates visual architectural diagrams and concept infographics (e.g. data flow, memory allocation, event loops).
- Sandbox: Executes student-submitted code snippets to verify correctness and return output/errors.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for safe code execution, Cloud Trace for observability
